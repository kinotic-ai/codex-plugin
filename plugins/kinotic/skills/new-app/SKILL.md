# New Kinotic App

Follow [create-app](../create-app/SKILL.md), using the application name, description,
and sign-in requirements already supplied. Ask only for missing information needed
to proceed. That workflow covers connection, platform-created repository provisioning,
scaffold verification, the first entity, and deployment verification when release is
authorized. Load the entity, service, frontend, and deployment skills as needed.
